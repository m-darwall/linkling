How to play

Instrucciones

At the top of the page is the first word in a list you can add to.

El objetivo es encontrar palabras que terminen en todas las parejas en la palabra al final de la página.

You can only add words that overlap with the previous word in the list by 2 letters or more.

Cuando encuentra palabras, puede añadirlas a la cadena.

The aim of the game is to have the list contain words that end in each of the underlined pairs of letters at the bottom.

Cuando encuentra palabras, puede añadirlas a la cadena.

Example

Ejemplo

If the last word was "education", you could perhaps add "onset", "ionic" or "educational".

Si la palabra anterior fuera "almacén", puede añadir "énfasis" o "céntimo".

Scoring

Puntos

You gain points for each word that ends in a new target pair. You lose points for each "undo" and each word without a target ending.

Ganará puntos por encontrar las parejas y perderá puntos por usar el botón de deshacer o usar palabras que no terminan con parejas necesarias.

There are also bonus points for finding the pairs in order and for not using any words without a target ending.

Ganará puntos por encontrar las parejas y perderá puntos por usar el botón de deshacer o usar palabras que no terminan con parejas necesarias.

There is always a solution that unlocks the pairs in order without any excess words.

Ganará puntos por encontrar las parejas y perderá puntos por usar el botón de deshacer o usar palabras que no terminan con parejas necesarias.
