# Linkling

A word game about chaining together words to unlock endings. You can play it [here](https://m-darwall.github.io/linkling). 

## Future improvements
- support for other languages
- potential hint and give up buttons
- archive
- instruction clarity
- tutorial
- faster page loading
- custom game creator
